# RustMFA v1 test vectors

`v1.json` is generated by `cargo run -p rustmfa-contract --bin gen_vectors` from a fixed
**public test key** (private scalar `0x11` repeated 32 times). Never use this key in production.

## Fields

- `key.spki_der_b64`: public key, base64 (standard) of X.509 SubjectPublicKeyInfo DER.
- `key.pkcs8_der_b64`: matching private key, for platform tests that must produce signatures.
- `challenge_cases[]`: `fields` (the six canonical message fields), `message` (expected
  canonical string, empty if building must fail), `signature_b64url` (the value submitted:
  raw 64-byte R||S, base64url no padding, or a DER blob for the rejection case),
  optional `signature_der_b64url` (DER form of the valid signature: converting it must give the
  same bytes as `signature_b64url`), `expect`.
- `request_cases[]`: `method`, `path` (with query), `ts` (Unix seconds), `nonce`, `body_b64`
  (standard base64), `signing_string`, `signature_b64url`, `expect`.
- `expect`: `ok`, `InvalidField`, `InvalidExpiresAt`, `BadSignatureEncoding`, `BadPublicKey`, `VerifyFailed`.

## Rule for every implementation (including Android)

Load this file in unit tests. For each case rebuild the `message` or `signing_string` from the
inputs and compare to the stored string; run signature verification; the outcome must equal
`expect`. Building errors (`InvalidField`, `InvalidExpiresAt`) are checked before verification.
